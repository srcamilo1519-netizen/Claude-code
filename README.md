# Claude-code

Proyectos web interactivos de un solo archivo.

## 🪐 Sistema Solar Explorador

`sistema_solar_explorador.html` — Escena 3D interactiva del sistema solar construida con [Three.js](https://threejs.org/).

**Características:**
- Sol central con luz puntual, halo brillante animado y rotación.
- Los 8 planetas orbitando en tiempo real con tamaños proporcionales, colores/texturas procedurales y velocidades orbitales distintas.
- Órbitas dibujadas visualmente, rotación de cada planeta sobre su eje (con inclinación axial), anillos de Saturno y Urano, y la Luna terrestre.
- Click/tap en el Sol o cualquier planeta para ver su ficha informativa (distancia, diámetro, día, año, características).
- Zoom y rotación con mouse o gestos táctiles (OrbitControls).
- Botones para **parar/reanudar** las órbitas, mostrar/ocultar trayectorias, centrar la vista y un control deslizante de velocidad.
- Responsivo y optimizado (pixel ratio limitado, texturas procedurales sin descargas externas) para desktop y mobile.

Para usarlo, abre el archivo en cualquier navegador moderno con conexión a internet (carga Three.js desde CDN).
